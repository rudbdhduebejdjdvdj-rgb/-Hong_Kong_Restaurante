# Hong Kong Restaurante — propuesta web

Web conceptual para Restaurante Hong Kong, Guadalajara (España).

- Sitio estático HTML/CSS/JS, sin build.
- Despliegue previsto mediante GitHub Pages y GitHub Actions.
- Los textos, imágenes de platos, carta, precios y horarios son provisionales y deben validarse con el establecimiento.
- Esta propuesta no es una web oficial ni implica autorización del restaurante.
